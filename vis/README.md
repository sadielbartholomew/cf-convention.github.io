# Visualisations for the CF Standard Names

This directory has scripts and outputs to generate visualisations from the data in the
Standard Name Table. For example, it is useful to plot to view the total number of names
over time and per version, as well as visual means to represent the set of names added
for a given version or set of versions, so that interested parties can quickly get an
impression of the history and diversity, for example, of the set of names.


## Total number of Standard Names over time and per release

A plot showing the total number of names.

## Standard Names, word clouds

Word cloud visualisations of sets of names of relevance, for example the set added for a
given version, or the full set at a given point in time.
